🏥 Pulse HMS – Hospital Management System

Healthcare Reimagined

Pulse HMS is a web-based Hospital Management System designed to simplify hospital operations and improve healthcare management through a centralized digital platform.

✨ Features

- Patient Portal – Patient access and appointment management.
- Doctor Portal – Doctor dashboard and consultation schedules.
- Staff Portal – Receptionist and hospital staff operations.
- Appointment Management – Book and manage appointments.
- Doctor Management – Manage doctor details and schedules.
- Patient Management – Maintain patient records.
- Billing & Invoices – Manage billing information.
- Pharmacy & Inventory – Track medicine and stock details.
- Prescriptions – Manage prescription records.
- Triage Management – Support patient assessment workflows.

🛠️ Technologies Used

Frontend

- React.js
- Vite
- JavaScript
- Tailwind CSS

Backend

- Node.js
- Express.js

Database

⚙️ Installation & Setup

1. Clone the repository:

git clone https://github.com/Atiya0615/Hospital-Management-System.git

2. Open the project folder.

3. Install backend dependencies:

cd hospital-api
npm install

4. Configure your backend environment variables in a ".env" file.

5. Install frontend dependencies:

cd ../hospital-frontend
npm install

6. Configure the frontend API URL and database connection.

7. Start the backend and frontend using the scripts configured in their respective "package.json" files.

🔐 Security

- Keep database credentials and API secrets in environment variables.
- Never upload ".env" files or private credentials to GitHub.
